# ライフゲーム (Conway's Game of Life)

純粋な HTML5 / CSS3 / JavaScript で構築された、モダンでレスポンシブかつモノトーン基調の**ライフゲーム（Conway's Game of Life）** Webアプリケーションです。

---

## 主な特徴

- **モノトーン＆ミニマルデザイン**: 黒と白を基調としたダークトーンの洗練されたUI。視認性と高いコントラストを追求。
- **高性能 Canvas レンダリング**: Retina / High-DPI ディスプレイにネイティブ対応し、60 FPSの滑らかなセルオートマトン描画を実現。
- **完全レスポンシブ対応**: PC・タブレット・スマートフォンすべてに最適化。タッチ操作（タップ/ドラッグでのセル描画・消去）に対応。
- **柔軟な再生・速度制御**:
  - デフォルト速度: **0.5秒（500ms）毎に1世代**進行。
  - 20ms〜1000msまで無段階調整可能な速度スライダー、加減速ボタン。
  - 1世代ずつのコマ送り（Step）、一時停止/再生、全消去、ランダム配置。
- **盤面サイズの変更**:
  - 最小サイズ: **10 × 10**
  - プリセット: 10×10, 20×20, 30×30, 50×50（標準）, 80×80, 100×100, 画面フィット, カスタム指定（最大200×200）。
  - トーラス状の境界ループ（ON/OFF）切り替え可能。
- **4カテゴリーの充実したプリセットライブラリ**:
  1. **固定物体 (Still Lifes)**: ブロック, 蜂の巣, パン, ボート, タブ (風呂桶), 池
  2. **振動子 (Oscillators)**: ブリンカー (周期2), ヒキガエル (周期2), ビーコン (周期2), パルサー (周期3), 銀河 / コックの銀河 (周期8), ペンタデカスロン (周期15)
  3. **移動物体 (Spaceships)**: グライダー, 軽量宇宙船 (LWSS), 中量宇宙船 (MWSS), 重量宇宙船 (HWSS)
  4. **繁殖型 (Methuselahs & Puffers)**: ダイハード (130世代で消滅), ドングリ (5206世代生存), rペントミノ, ゴスパーのグライダー銃, シュシュポッポ列車 (汽車 / Switch Engine)
- **直感的なスタンプ配置モード**: パターンを選択するとマウスカーソルに半透明のゴーストが表示され、盤面上の好きな場所にクリックで配置可能。90度回転や中央ワンクリック配置にも対応。
- **多言語対応 (日英自動判別 & 手動切替)**:
  - ブラウザの言語設定（`navigator.language`）を自動検出し、日本語環境では日本語、それ以外では英語で表示。
  - ヘッダーの `EN` / `JA` ボタンからワンクリックで切替可能（`localStorage` に保存）。
- **図解付きルール解説・ヘルプモーダル**:
  - ライフゲームの4大ルール（誕生・生存・過疎・過密）を図解で分かりやすく解説。
  - ショートカットキーや操作ガイドを一覧表示。

## ライフゲームの基本ルール

ライフゲームは、格子状のマス目（セル）の周囲8マスの生存数によって、次の世代の生死が決まるシミュレーションです。

| ルール | 条件 | 次世代の状態 |
| :--- | :--- | :--- |
| **1. 誕生 (Birth)** | 死んでいるセルに隣接する生きたセルが **ちょうど3つ** ある | **新しい生命が誕生** (■) |
| **2. 生存 (Survival)** | 生きているセルに隣接する生きたセルが **2つ または 3つ** ある | **次の世代も生存** (■) |
| **3. 過疎 (Underpopulation)** | 生きているセルに隣接する生きたセルが **1つ以下** になる | **過疎により死滅** (□) |
| **4. 過密 (Overpopulation)** | 生きているセルに隣接する生きたセルが **4つ以上** になる | **過密により死滅** (□) |

## 操作方法 & キーボードショートカット

| 操作 / 機能 | マウス・タッチ | ショートカットキー |
| :--- | :--- | :--- |
| **セルの描画 / 消去** | 盤面をクリックまたはドラッグ | - |
| **再生 / 一時停止** | 再生ボタン | <kbd>Space</kbd> |
| **1世代進む (コマ送り)** | 進むボタン | <kbd>S</kbd> / <kbd>→</kbd> |
| **盤面を全消去** | 全消去ボタン | <kbd>C</kbd> |
| **ランダム生成** | ランダムボタン | <kbd>R</kbd> |
| **パターンの回転** | 回転ボタン | <kbd>Z</kbd> / <kbd>R</kbd>（配置中） |
| **選択解除 / 閉じる** | キャンセル / ✕ | <kbd>Esc</kbd> |
